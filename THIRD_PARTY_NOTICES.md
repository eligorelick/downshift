# Third-party notices

Downshift itself is released under the [MIT License](LICENSE). The website and the Windows app bundle the open-source packages below. The license text for each is copied from the package's `LICENSE` file in `node_modules`, at the version in `bun.lock`.

| Package | Version | License | Where it is used |
|---|---|---|---|
| react | 18.3.1 | MIT | Website and Windows app (user interface) |
| react-dom | 18.3.1 | MIT | Website and Windows app (user interface) |
| scheduler | 0.23.2 | MIT | Website and Windows app (used by react-dom) |
| idb | 8.0.4 | ISC | Website and Windows app (history storage in IndexedDB) |
| workbox-window | 7.4.1 | MIT | Website and Windows app (registers the offline service worker) |
| workbox-core, workbox-routing, workbox-precaching, workbox-strategies | 7.4.x | MIT | Website and Windows app (the offline service worker's runtime, generated by `vite-plugin-pwa`) |
| vite-plugin-pwa | 0.20.5 | MIT | Website and Windows app (a small helper that registers the service worker) |
| vite | 5.4.21 | MIT | Website and Windows app (a small module-preload helper the build adds) |

Apart from the two small helpers above, build and test tools (Vite, TypeScript, Biome, Playwright, electron-builder and so on) are not part of what you run, so they are not listed here. The Vite text below is its core license; the third-party code bundled inside Vite itself is not shipped in the app.

## Electron and Chromium

The Windows app includes Electron and Chromium. Their licenses ship inside the app, next to the executable: `LICENSE.electron.txt` and `LICENSES.chromium.html` (in the installed app folder, and in `packages/desktop/release/win-unpacked` when built from source).
